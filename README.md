# عبقرينو Studio Ultimate
المنصة المتكاملة لإنشاء البرامج وإصلاحها، المزودة بعقل اصطناعي مستقل ونظام تحكم حصري في التسليم.

## المكونات الأساسية للمشروع:
1. **Creation Studio (استوديو الإنشاء):** 15 مرحلة هندسية من الفكرة والمناقشة والتصميم وتوليد الأكواد وقواعد البيانات وحتى إتمام الاختبارات.
2. **Repair Studio (استوديو الفحص والإصلاح):** تشخيص عميق، تقارير فحص بالأدلة، تعديلات موضعية منضبطة مع Diff View وتراجع فوري (Rollback).
3. **العقل الاصطناعي المستقل (Neural Brain):** معمارية Transformer Decoder (16 طبقة، 125M معامل)، مجزئ عربي BPE، مسار تدريب، وتقييم لمقاومة الهلوسة.
4. **نظام التحكم الحصري في تسليم البرامج (الباب العاشر):** السيطرة المطلقة لصاحب المنصة عبر رقم المحفظة والاتصال **`01153747612`**، مع حظر التنزيل التلقائي للعميل وتأكيد الإرسال اليدوي عبر واتساب.
5. **استوديو المجسمات 3D (Three.js PBR):** نماذج إجرائية مركبة من 3-12 جزءاً مع إضاءة استوديو ولوحة تحكم مدمجة قابلة للطي بنقرة واحدة.
6. **نظام النسخ الاحتياطية الحقيقي:** توليد أرشيف ZIP متكامل يحتوي على كافة ملفات الشيفرة المصدرية الحقيقية جاهز للحفظ في `/sdcard/Download/عبقرينو-سوبر-نسخة-كاملة.zip`.

## التشغيل السريع:
```bash
npm install
npm run dev
```
افتح المتصفح على `http://localhost:3000`.
كلمة مرور الإدارة الافتراضية: `abqarino2026`.
